# JAMES Linux

JAMES Linux is an autonomous AI pentesting agent designed specifically for Linux environments (tailored for Parrot OS). It features a native PyQt6 GUI and interfaces directly with industry-standard security tools such as `aircrack-ng`, `nmap`, and `hashcat`.

## Setup
1. Clone the repository on a Parrot OS or Kali Linux machine.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the GUI: `python main.py`

*Note: This project is under active development. See `implementation_plan.md` and `task_list.md` for current progress.*
