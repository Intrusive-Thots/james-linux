Implements the core idea of the Self-Evolving Decision Graph Engine (SEDGE) as detailed in the design document.

This builds a directed weighted decision graph where:
- Nodes represent system states or actions.
- Edges act as transitions between decisions.
- Weights hold learned success utility scores.

Features included:
- State Node Model
- Edge Model (Learning Paths)
- Decision Graph Core
- Execution Feedback Learning
- Decision Engine (Policy Layer)
- Self-Evolution Loop

Includes mappings to the Parrot WiFi system showing node mapping and real evolution behavior.
